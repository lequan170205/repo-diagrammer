# Research basis

Repo Diagrammer's workflow and quality profiles are informed by:

- C4 model: https://c4model.com/
- C4 notation: https://c4model.com/diagrams/notation
- C4 review checklist: https://c4model.com/diagrams/checklist
- Structurizr model/views: https://docs.structurizr.com/
- Structurizr DSL: https://docs.structurizr.com/dsl/language
- Mermaid syntax/layouts: https://mermaid.js.org/intro/syntax-reference.html
  and https://mermaid.js.org/config/layouts
- Mermaid sequence/ER/state/use-case/swimlane syntax under https://mermaid.js.org/syntax/
- PlantUML UML diagram documentation: https://plantuml.com/
- Graphviz dot/attributes: https://graphviz.org/docs/layouts/dot/
  and https://graphviz.org/doc/info/attrs.html

Durable principles adopted:
- model facts separately from views;
- one abstraction/question per view;
- labels and relationship direction must explain intent;
- notation needs a legend when it carries meaning;
- extract deterministic structure before hand-tracing;
- select renderers by semantics;
- visual readability is a quality gate, not decoration;
- stable IDs/names across a diagram set.

Repository evidence remains authoritative for the system being diagrammed.
